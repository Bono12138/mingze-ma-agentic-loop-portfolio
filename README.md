# Mingze Ma — From Copilot to the Agentic Loop

A trilingual project portfolio covering financial-risk delivery, controlled Agent workflows, reusable internal tools and the Bono Insight capability and knowledge foundation.

## Languages

- 简体中文
- 繁體中文
- English

## Local preview

```bash
npm install
npm run build
npm run serve
```

The published site uses only project diagrams, authorised materials and screenshots from real tools or live pages. The World Cup Rank Room image links to the live site at <https://worldcup-rank-room.pages.dev/>.
